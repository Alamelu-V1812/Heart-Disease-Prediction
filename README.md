# Heart Disease Prediction Using Machine Learning

## Project Description
This project is a Machine Learning-based system for predicting the presence of heart disease using patient health-related data.
The project applies classification algorithms to analyze the given medical features and predict whether a person is likely to have heart disease.

## Objective
The main objective of this project is to use Machine Learning techniques to analyze health data and predict heart disease.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Machine Learning Models
The project uses classification algorithms for heart disease prediction.

## Project Workflow
1. Load the dataset
2. Explore and understand the data
3. Perform data preprocessing
4. Select the required features
5. Split the data into training and testing sets
6. Train Machine Learning models
7. Evaluate the models
8. Predict heart disease based on the input data
m## Dataset
The dataset contains health-related attributes used for predicting the presence of heart disease.

## Project File
- `Heart_Disease_Prediction.ipynb` – Contains the complete Python code, analysis, Machine Learning implementation, and outputs.

## Conclusion
This project demonstrates how Machine Learning can be applied to health-related data for heart disease prediction. It provides a practical example of using classification techniques for predictive analysis.
